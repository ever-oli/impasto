# The notch's feature map

What a user can do with the shell, and how each thing is proved. One file
per journey. The harness is the `notch-drive.sh` helper that ships with the
`verify-notch` skill; the raw IPC is always available too.

The map is the maintained source: a proof that drives one convenient entry
point is incomplete when the map lists others. Add a file when a journey is
added to the shell, and keep the `Gotchas` honest: a journey that cannot
pass right now says so, and says why.
