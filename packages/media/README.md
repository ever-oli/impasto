# The catalogue

Anime from AniList, films and series from TMDB, and the
watching: the picture plays in the island terminal.

    scripts/  →  ~/.config/quickshell/scripts/   (stream.py)
    bin/      →  ~/.local/bin/                 (notch-watch, notch-video,
                                               notch-subs, notch-resolve.mjs,
                                               notch-sources)

The `install` file says where each of its files lands; `./setup files`
follows it.
