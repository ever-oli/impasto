# The assistant

The ask bridge, the four engines, and the harness that learns.

    scripts/  →  ~/.config/quickshell/scripts/   (ask.py and its parts)
    notch/    →  ~/.config/notch/              (the modes, the memory)
    bin/      →  ~/.local/bin/                 (notch-ask-cli, notch-harness)

The `install` file says where each of its files lands; `./setup files`
follows it.
